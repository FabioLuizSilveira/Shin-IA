## Como usar

- **Designers/PMs**: comecem em 00 → 01 → 03. O gate do doc 03 aprova telas.
- **Engenharia**: docs 09 (tokens) + 10/19 (componentes) + 11/18 (motion e
  performance) são o contrato de implementação da Wave 3.
- **Marca**: doc 02 está sob **Brand Lock** — alterações exigem aprovação
  formal.

## Princípio-mãe

> Operações Inteligentes em Movimento — calma, inteligência, fluxo, elegância,
> precisão. Nada evoca ERP, admin ou template.
